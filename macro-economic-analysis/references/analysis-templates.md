## 一、执行摘要

### 研究背景

[简述分析的时间范围、覆盖区域、研究目的。例如：YYYY年是"十四五"规划收官之年，面对复杂多变的国内外经济环境，中国经济在政策调控下实现了预期增长目标。本报告旨在系统分析YYYY年宏观经济运行态势，并对预测年份经济走势进行预测。]

**（一）经济增长方面**：[GDP总量及增速、季度走势、产业结构变化等核心判断]

## 十一、快速判断框架

### 11.1 增长判断决策树

```
PMI > 50?
├── 是 → 工业增加值 > 5%?
│         ├── 是 → 增长偏强
│         └── 否 → 增长中性
└── 否 → PMI < 48?
          ├── 是 → 增长偏弱
          └── 否 → 增长中性偏弱
```

### 11.2 通胀判断决策树

```
CPI > 3%?
├── 是 → 通胀上行压力
└── 否 → PPI < 0?
          ├── 是 → 通缩压力
          └── 否 → 通胀温和
```

### 11.3 政策判断决策树

```
增长判断 + 通胀判断
├── 增长强 + 通胀高 → 政策收紧
├── 增长弱 + 通胀低 → 政策宽松
├── 增长强 + 通胀低 → 政策温和
└── 增长弱 + 通胀高 → 政策两难
```
